**Office Master Studio** 是一款现代化、高颜值、极速、无后端依赖的纯前端一站式线上办公超级处理工作台。所有转换、排版、抠图、图像处理、文档比对与 PDF 生成算法均在用户浏览器本地离线运行，保护商业合同、财务报表与个人隐私绝对安全！

---

## 🌟 核心功能矩阵

### 1. 📄 智能图像扫描与文档矫正 (DocScan)
- **智能四角识别**：自动检测发票、单据与倾斜纸张四角。
- **高精度透视变换**：双线性插值将畸变照片拉直压平为标准扫描件。
- **扫描全能王同款滤镜**：彩色增强（白底增白去阴影）、黑白扫描、印章强化、高清灰度。
- **多模态 AI 视觉解析**：兼容 OpenAI 协议，直连 ChatGPT、Gemini、通义千问、智谱 GLM、Kimi、MiniMax 等提取文字/表格/发票。

---

### 2. 🔄 全能文件格式互转中心 (Converter Hub)
- 📑 **PDF ⇄ Word (.docx)**：精准提取 PDF 排版段落与标题结构，生成可编辑 Word。
- 📊 **PDF ⇄ Excel (.xlsx)**：智能识别 PDF 表格并生成标准 Excel 工作簿。
- 📽️ **PDF ⇄ PPT (.pptx)**：逐页渲染高清演示文稿幻灯片。
- 🖼️ **PDF ⇄ 高清图片包 (ZIP)**：多页 PDF 批量渲染无损 PNG 并一键打包 ZIP。
- 🖼️ **多张图片合并转 PDF (Images to PDF)**：批量合并多张图片并自动排版生成 PDF。
- 📈 **Excel ⇄ CSV ⇄ JSON ⇄ Markdown 表格**：四向表格数据秒级互转。

---

### 3. ✍️ Word / 文本智能公文排版与美化 (Document Formatter)
- **公文要素快捷插入**：一键插入发文字号（〔2026〕18号）、主送机关、附件说明、落款成文日期。
- **一键格式清洗**：去除多余空行、去除首尾空格、中英文盘古空格（如 `iPhone 16 发布`）、标点中英文纠偏。
- **国标公文规范排版**：方正小标宋大标题、黑体二级标题、楷体三级标题、仿宋三号正文、首行缩进 2 字符、1.5 倍行距。
- **真实 Word 导入与导出**：支持直接导入本地 `.docx` 进行排版，并一键导出真实排版的 `.docx` 文件。
- **AI 智能公文润色**：结合 AI 一键纠正错别字、病句，提升严肃规范的行文风格。

---

### 4. ✂️ 印章与手写签名透明抠图提取器 (Seal & Signature Extractor)
- 🔴 **红色印章提取**：智能分离公章、财务章、合同章，自动过滤黑字与白纸背景，增强红墨饱和度，生成透明 PNG。
- ✍️ **手写签名提取**：精准提取黑色/蓝色手写笔迹，自动将纸张背景转为 100% 透明通道。
- **一键复制与下载**：支持一键下载无损透明 PNG 或直接复制到剪贴板。

---

### 5. 📝 中小学生作业纸与描红字帖模板库 (Grid & Paper Templates)
- **✍️ 自定义字帖描红模式 (Trace Mode)**：支持输入任意汉字或一键载入《三字经》、《静夜思》等古诗词，在田字格/米字格中生成浅灰描红字水印，供孩子描红练字！
- **丰富纸张规格**：支持 **A4 (210×297mm)**、**A5 (148×210mm)**、**A3 (297×420mm)**，支持横向/纵向。
- **专业格线模版**：
  - 🀄 **拼音田字格**（带拼音四线三格的田字格）
  - 🔲 **纯田字格**（汉字规范书写）
  - ✳️ **米字格**（毛笔/硬笔书法临摹）
  - 📅 **日字格**（数字规范书写）
  - 🔤 **英语四线三格**（字母单词书写）
  - 🎼 **音乐五线谱**（标准乐谱纸）
  - 🎸 **吉他/尤克里里六线谱**（TAB 指弹谱）
  - 📝 **作文稿纸**（20×20 方格）
  - ▫️ **5mm 点阵坐标纸** 与 📐 **方格坐标纸**
- **个性化设置与清晰度优化**：适应屏幕宽度一键撑满、无级缩放控制、格线粗细调节（1px~4px）、经典红/护眼绿/复古灰/墨水蓝四色切换。
- **高清导出与打印**：300 DPI 矢量级超清 PDF 一键生成与浏览器直接打印。

---

### 6. 🔍 双文档 / 商务合同专业差异比对中心 (Document Diff)
- **📄 支持直接上传真实文件**：支持直接上传两份 **Word (.docx)**、**PDF (.pdf)**、**TXT** 或 **Markdown** 文件进行毫秒级自动解析与文本比对！
- **📊 差异统计看板**：实时计算新增字数（+X）、删除字数（-Y）与整体变更率（Z%）。
- **🎨 修订标记高亮 (Redline Stream)**：绿色醒目高亮新增内容，红色删除线标记删除内容。
- **🤖 AI 合同实质性变更与法律风险审查**：一键调用 AI 提炼两份合同关于交期、付款方式、违约责任、免责条款的核心差异，并输出资深律师级法律风险审查报告！
- **💾 导出比对报告**：支持一键导出比对报告 HTML 与打印归档。

---

### 7. 🛠️ 办公高效实用小工具箱 (Office Super Tools)
- 📑 **PDF 瑞士军刀**：多 PDF 毫秒级合并、按页码范围（如 `1-3, 5`）精准拆分提取。
- 🛡️ **商业敏感信息脱敏器**：一键识别并脱敏身份证号、手机号、银行卡号与邮箱。

## 🚀 快速使用

无需安装任何后端环境，双击打开 `index.html` 即可使用！

```bash
# 克隆仓库
git clone https://github.com/2867094562a-code/docscan-studio.git

# 进入目录
cd docscan-studio

# 在浏览器中直接打开 index.html 即可使用！
```

## 🔒 隐私与安全

- 本工具所有格式转换、公文排版、印章抠图、文档比对与 PDF 生成算法均在 **本地浏览器** 内完成。
- AI 识别、公文润色与合同审查功能直接由用户填写的 API Key 与对应 AI 服务商通讯，**密钥仅保存在用户浏览器的 LocalStorage 中**，绝不经过任何第三方服务器。
