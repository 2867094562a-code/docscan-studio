# 演示文稿预览与水印

演示文稿预览使用本地打包的 [@web-ppt/core 0.5.0](https://github.com/unStone/web-ppt)（MIT）及 fflate 0.8.3（MIT）；相应许可证在 `vendor/`。运行时通过普通脚本标签加载，保留直接双击 `index.html` 的方式。其余既有依赖（包括 PDFLib）仍通过 CDN 加载，需要网络或已缓存资源。

PPTX 按文件内幻灯片顺序解析并预览；支持基础文字、图片、形状、表格及其主题的一部分。复杂图表、SmartArt、动画、视频、嵌入字体和精细版式可能不完整；检测到图表、SmartArt 或音视频时会额外提示，使用前请逐页检查。PPT 老格式由同一渲染器尝试读取，复杂及加密文件可能失败；无法打开时请在演示软件中另存为 PPTX 后重试。每页按原尺寸比例渲染到位图并嵌入 PDF，**导出文字不可搜索或编辑**，并非无损还原。可关闭预览中止后续页面处理。限制：文件最多 25 MB、100 页；PPTX 解压总大小最多 160 MB、3000 个条目，不接受 ZIP64。

水印对 PDF 每页叠加透明的中文图片层，不栅格化原页面；图片导出 PNG。文字、颜色、角度和透明度可调。文件最多 25 MB，PDF 最多 100 页，图片最多 1600 万像素。水印改变文件，数字签名将失效；加密或损坏的 PDF 可能无法处理。每次输出新文件，原文件不会被覆盖。

`tests/fixtures/` 的两份 PPTX 使用 PptxGenJS 3.12.0 生成，内容为本项目自制示例。`node tests/presentation-regression.cjs` 检查本地转换流程（使用模拟渲染器），`node tests/templates-regression.cjs` 检查模板绘图几何；真实渲染需浏览器验证。

二维码与 Code 128 可导出 SVG 矢量路径，二维码保留四模块静区；二维码由本地固定版本 qrcode-generator 1.4.4 生成，并用 TextEncoder 对混合中文、英文和表情编码为 UTF-8；许可保存在 vendor。Code 128 限 1–128 个可打印 ASCII 字符，不对不支持的中文静默截断。水印图案 SVG 是独立透明文字图案，采用当前的文字、颜色、角度和透明度，不包含源文件。
